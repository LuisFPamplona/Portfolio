## REVISEI

O Revisei é um sistema completo de organização de estudos com foco em consistência, progresso e motivação — basicamente um “Duolingo + Notion + gamificação”, mas construído por você do zero.

Aqui vai uma descrição clara (nível portfólio / LinkedIn 👇):

💻 Revisei — Plataforma de Gestão de Estudos com Gamificação

O Revisei é uma aplicação full stack desenvolvida para ajudar usuários a organizar, acompanhar e manter consistência nos estudos através de metas, tarefas e recompensas.

A plataforma permite que o usuário gerencie seu aprendizado de forma estruturada, dividindo conteúdos em matérias e tópicos, enquanto acompanha sua evolução ao longo do tempo.

🚀 Principais funcionalidades
🔐 Autenticação
Registro e login de usuários
Proteção de rotas com JWT
Controle de acesso por usuário
👤 Gestão de usuário
Visualização de perfil
Atualização de meta diária de estudos (dailyGoal)
Acompanhamento de progresso
📚 Organização de estudos
Criação de matérias
Criação de tópicos dentro das matérias
Controle de status (pendente / concluído)
Registro de conclusão com data (completedAt)
🎮 Gamificação (diferencial forte)
Sistema de XP e gemas
Recompensa por revisões válidas
Proteção contra “farm” de pontos
Feedback imediato ao completar tarefas
🧠 Regras de negócio inteligentes
Validação de dados com Zod
Controle de integridade das ações do usuário
Sincronização automática de progresso entre tópicos e matérias
🧪 Qualidade de código

🎯 Objetivo do projeto

O Revisei foi desenvolvido com o objetivo de:

Aplicar conceitos reais de desenvolvimento full stack
Simular um sistema próximo do mercado
Praticar arquitetura, regras de negócio e escalabilidade
Criar um projeto forte de portfólio
🧩 Diferencial

O grande diferencial do Revisei não é só CRUD — é a lógica por trás:

Sistema de recompensas bem definido
Prevenção de abuso (anti-farm)
Sincronização entre entidades
Backend estruturado com validação e testes
